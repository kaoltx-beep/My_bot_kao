# Rules

This document outlines the rules for contributing to the Jarvis project.

## Rule 1

ห้ามเริ่มแก้โค้ดก่อนอ่าน

```
AI_CONTEXT.md
PROJECT_STATUS.md
CURRENT_TASK.md
TODO.md
```

---

## Rule 2

ทำเพียง

```
1 Task ต่อ 1 Session
```

---

## Rule 3

หลังทำเสร็จต้องอัปเดต

```
CURRENT_TASK.md
PROJECT_STATUS.md
CHANGELOG.md
TODO.md
NEXT_AI.md
```

---

## Rule 4

Commit ทุกครั้ง

ตัวอย่าง

```bash
git add .
git commit -m "Complete Memory Search"
git push
```

---

## Rule 5

ห้าม Rewrite ทั้งระบบ

ให้แก้เฉพาะ

```
Module ที่ได้รับมอบหมาย
```

---

## Rule 6

รักษา Compatibility

ห้ามทำให้

* Telegram
* Memory
* Expense
